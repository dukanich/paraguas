# PARAGUAS Development Rules

## Project Structure
- Follow the task list in TASKS.md for development order
- Each feature should be implemented in its own branch
- All code changes must be tested before merging

## Code Organization
- Use modular architecture
- Separate concerns (UI, data, voice)
- Implement proper error handling
- Follow best practices for PWA development

## Development Guidelines
1. Start with core features before adding enhancements
2. Implement offline functionality early
3. Focus on performance optimization
4. Test thoroughly on mobile devices
5. Document all major changes

## Priority Order
1. Core Features
2. Data Management
3. User Interface
4. Voice Integration
5. Performance Optimization
6. Testing
7. Documentation
8. Future Enhancements

## Quality Checks
- Code must be tested for offline functionality
- Voice synthesis must work in both online and offline modes
- UI must be responsive on all devices
- Performance must be optimized for mobile use
- All features must be documented
